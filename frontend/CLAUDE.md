### Frontend Design

- Whenever implementing any feature force it be a desktop alike design . not a webpage

- Feature should be responsive with mobile screen dimensions
- always use @design/cognium-design.html for UI/UX reference

- No over complicated code , bare minimum code for UI design

- NO OVER COMPLICATED CODE FOR LOGICS , ASK EXPLICITLY BEFORE TAKING ANY DECISIONDEVIATED FROM THE PLAN GIVEN

- Permission should be asked before any external dependency installations

- After each implementation tests should be run . Dont fix anything when faiuls ask wheather to fix or not
