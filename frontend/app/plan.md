#### Landing Page

- use [@/design/cognium-design.html for reference ](../../design/cognium-design.html), for Landing page design

### Libraries to use

- shadcn
- tailwind
- zod (validation)
- react forms

## Branding

- Cognium branding in a very modern way preferably in blended colors(gradient / glossy)

## Description

- description should be as per the design just below the branding

## User Input

- user input field to enter user_name
- dont accept spaces or caps (symbols , numbers , smallcase letters are expected)
- If any invalid name is entered , show error of hint that its not allowed with this example : john@123 ,#mary07

## Validation

- Use zod and react-hook-form for input validation

## Submit Action

- on continue if validation succed then move to section1 in risk-assessment
