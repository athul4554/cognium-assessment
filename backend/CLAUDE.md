### Backend Design

- Any API implementation should have error handling

- ALways keep constants and configs in seperate file, dont mix it with buisiness logic layer

- NO OVER COMPLICATED CODE FOR LOGICS , ASK EXPLICITLY BEFORE TAKING ANY DECISION DEVIATED FROM THE PLAN GIVEN

- Permission should be asked before any external dependency installations

- After each implementation tests should be run . Dont fix anything when fails ask wheather to fix or not

- Dont do any db changes , ask to do it manually
